# Exported music-platform icons

These are 512 x 512 PNG exports of the same Font Awesome Free 6.4.0 brand glyphs referenced by `index.html`.

| PNG | Font Awesome source icon |
| --- | --- |
| `spotify.png` | `fa-spotify` |
| `apple-music.png` | `fa-apple` |
| `youtube-music.png` | `fa-youtube` |
| `amazon-music.png` | `fa-amazon` |

The files use black monochrome artwork on transparent backgrounds, making them suitable for recoloring in another design tool. Apple and Amazon are the general brand glyphs used by the website, not separate Apple Music and Amazon Music app-badge artwork.

Source: [Font Awesome Free 6.4.0](https://github.com/FortAwesome/Font-Awesome/tree/6.4.0/svgs/brands). Font Awesome Free icons are provided under the [CC BY 4.0 license](https://fontawesome.com/license/free). Platform names and logos are trademarks of their respective owners.
